# PaymentButton

کامپوننت React/TypeScript برای نمایش دکمهٔ پرداخت.

## کاربرد

`PaymentButton` یک دکمهٔ قابل استفادهٔ مجدد است که:

- متن ثابت «پرداخت» را نمایش می‌دهد.
- از ظاهر Primary استفاده می‌کند.
- تمام عرض Container والد را می‌گیرد.
- به‌صورت پیش‌فرض برای ارسال فرم با `type="submit"` تنظیم شده است.
- سایر قابلیت‌های معتبر کامپوننت DIG Button، مانند `loading`، `disabled`، `onClick` و `className` را دریافت می‌کند.
